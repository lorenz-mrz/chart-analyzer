# Chart-Analyzer

Web-App zur Analyse von Chart-Daten (MT5, TradingView, Capital.com).

**Live-App:** https://dein-link.streamlit.app

## Funktionen
- CSV-Upload, Format wird automatisch erkannt
- Kennzahlen: Veränderung, Höchst/Tiefst, Volatilität
- Linien- und Kerzen-Chart mit einstellbarem SMA
- Zeitraum-Filter und CSV-Download
