# Chart-Analyzer

Web-App zur Analyse von Chart-Daten (MT5, TradingView, Capital.com).

**Live-App:** (https://chart-analyzer-for-trading.streamlit.app)

## Funktionen
- CSV-Upload, Format wird automatisch erkannt
- Kennzahlen: Veränderung, Höchst/Tiefst, Volatilität
- Linien- und Kerzen-Chart mit einstellbarem SMA
- Zeitraum-Filter und CSV-Download
- Gebaut mit Python, Streamlit und Plotly
- Backtest mit 3 Strategien (SMA-Kreuzung, Umkehrkerze, Ausbruch)
- Stop, Ziel in R und Kosten einstellbar
- Automatischer Long/Short-Gegentest (erkennt Beta statt Edge)
- Vergleich gegen Buy & Hold
